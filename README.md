# flicker-dot

The runtime player for [Flicker](https://flicker.laurie.fyi) — design dot-grid
loading spinners and drop them straight into your React app.

> **Status: pre-release.** The `<FlickerSpinner>` component and install
> instructions land with `v0.1.0`.

## Install

Available with the first release:

```bash
npm install flicker-dot
```

## Implementations

Ports and reimplementations of Flicker on other platforms will be listed here.
If you've built one, open a PR (please read the note on the name below first).
